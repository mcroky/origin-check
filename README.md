# 어디서 만들었지? — v0.9.1 공개 체험판

v0.9.1(2026-10-26): OCR 추출 점수가 같을 때 엔진 신뢰도로 동점을 해소합니다. 신뢰도는 제조국 증거가 아니며 원료와 완제품의 원산지를 구분하는 기존 원칙은 유지합니다.

**공개 주소:** https://mcroky.github.io/origin-check/ · [배포와 공개 범위](DEPLOYMENT.md)

공개판에서는 기기 내 OCR·라벨 제조국 표시 확인·30개 표본 검색을 제공합니다. **식약처 실시간 조회는 로컬 서버에서만 제공**합니다. 공개판의 라벨 분석 결과는 실제 식약처 조회 결과가 아닙니다. 인증키와 권한 미확인 검증 사진은 공개하지 않습니다. `validation/`의 사진·캡처·상세 측정 파일은 로컬 보관 자료로 공개 저장소에 포함하지 않습니다.

어두운 표의 행·칸 재인식과 두 식약처 자료 통합 검색을 추가했습니다. 바릴라 브라우저 한 사례에서 제품명·업체·용량 수동 수정 3→0을 확인했습니다. 타바스코는 두 자료 19건을 함께 받았고, 바릴라 CLI 조회는 시간 초과였으나 마지막 브라우저 조회는 두 자료 39건을 받아 입력 수정 없이 맞는 500g 자료와 대조했습니다. **136개 테스트·빌드 통과.** 실제 촬영 20장 평가는 사진이 없어 미실시이며 준비 양식만 만들었습니다. [최신 검증](TABLE_UNIFIED_VALIDATION.md). 아래는 이전 단계 기록입니다.

수입신고별 API 승인 후 기존 키로 실제 조회에 성공했습니다. 타바스코 60ml와 바릴라 일반 스파게티 500g의 제품 종류·규격 후보를 찾았고 이금기 320g은 미확인입니다. 바릴라 브라우저 검증은 검색어·업체·용량을 수동 보정했으며 자동 매칭 성공으로 세지 않습니다. 국가 표의 세로선·내용량 혼입 오류를 수정했고 **121개 테스트·빌드 통과**. [승인 후 검증 보고서](LEGACY_VALIDATION_REPORT.md). 아래 v0.7.0 이하는 당시 기록입니다.

식약처 자료 범위 안내·이전 자료 선택·띄어쓰기와 법인 표기 보정·여러 페이지 조회를 추가했습니다. 실제 법인 표기 차이로 0→1건 회복, 스파게티 3페이지 30건 수집과 후보별 출처 보존을 확인했습니다. 이전 자료 API는 현재 키로 AUTH_FAILED이므로 별도 활용승인 확인이 필요합니다. **118개 테스트·빌드 통과.** [검색 범위 검증 보고서](SEARCH_COVERAGE_REPORT.md). 아래 v0.6.0 이하는 이전 단계 기록입니다.

용량 영역 재인식·단위 대조·불확실한 값의 선택 버튼을 추가했습니다. 기존 5장과 새 브랜드 5장의 비교에서 정확한 용량 자동 입력은 **3/10→8/10**이었습니다. 타바스코·이금기·바릴라의 실제 검색도 확인했으나 사진과 같은 규격의 자료는 확인하지 못했습니다. 이름에 용량이 없으면 식약처 한글표시사항의 내용량을 대조해 다른 규격의 확정을 차단합니다. **109개 테스트·빌드 통과.** [용량·새 브랜드 검증 보고서](QUANTITY_VALIDATION_REPORT.md)를 참고하세요. 아래 v0.5.0 이하는 이전 단계 기록입니다.

원본·여백 제거 확대·명암 보강 OCR과 최대 3회 자동 재검색을 추가했습니다. 같은 한글 표시 5장 재검증에서 제품명 정확 일치 0→1장, 국가 표시 추출 3→5장, 같은 제품·용량의 실제 자료 후보 1→2건을 확인했습니다. 곡면 마요네즈와 티라미스는 검색어를 직접 고치지 않고 후보를 찾았습니다. 용량 단위·제품 종류·로트는 여전히 검토해야 합니다. **97개 테스트·빌드 통과.** [개선 검증 보고서](OCR_IMPROVEMENT_REPORT.md)를 참고하세요. 아래 v0.4.0 수치는 이전 단계 기록입니다.

실제 수입식품 이미지 12장(평면 한글 표시 4장·곡면 뒷면 1장·앞면/연출 7장)으로 제품명 추출부터 식약처 대조까지 검증했습니다. 줄바꿈 필드와 주소 혼입을 개선하고, 0건 재검색 제안·용량 불일치 차단을 추가했습니다. 티라미스 110g은 문구·용량을 사람이 검토한 뒤 같은 제품 종류의 자료와 국가 표시를 대조했습니다. 제품명 정확 일치는 5장 중 0장이며 곡면 OCR 실패가 남아 있어 자동 판별 정확도를 보장하지 않습니다. **83개 테스트·빌드 통과.** [실제 라벨 검증 보고서](REAL_LABEL_VALIDATION.md)를 참고하세요.

사진 제품명 추출 → 식약처 실조회 → 제품 정보 대조 → 국가 근거 비교를 연결했습니다.

1. 라벨 사진을 선택하거나 촬영하고 **제품명·제조국 함께 읽기**를 누릅니다.
2. 인식한 국가 문구를 수정·확인한 뒤 **식약처 제품 대조로 이동**을 누릅니다.
3. 자동 입력된 제품명과 수입업체를 검토해 조회합니다. 제품명이 빠졌다면 해당 영역을 선택해 다시 읽거나 검색어를 직접 입력합니다.
4. **검색 보조**가 켜져 있으면 띄어쓰기·법인 표기·읽힌 단어로 최대 6회, 같은 조건으로 최대 3페이지 조회합니다. 끄거나 조회를 취소할 수 있습니다. 실제 조회어와 식약처 표기 제안을 확인한 뒤 **이 자료와 대조**를 누르고 제품명·맛·용량·업체·유통기한을 실제 라벨과 대조합니다. 라벨 용량이 잘못 읽혔다면 수정하세요. 명확한 용량 불일치는 확정 버튼을 차단합니다.
5. 같은 제품 종류의 자료임을 확인하면 중국/다른 국가/자료 상충/확인 불가 결과와 두 출처를 함께 표시합니다. 실제 날짜·로트가 없으면 보유 제품의 해당 수입 건까지 일치함을 뜻하지 않습니다. JSON에 적용 범위·선택 자료·조회 조건·시각·OCR 원문과 확인 이력을 포함합니다.

사진·전체 OCR 원문은 기기에서 처리하고, 제품 조회를 누르면 제품명·선택 수입업체명·페이지 조건만 서버로 전송합니다. 사진을 바꾸거나 검색 조건·라벨 문구를 수정하면 이전 대조 결과를 해제합니다. 식약처 조회를 사용할 수 없어도 라벨 문구 확인은 가능합니다.

v0.3.0 검증: 테스트 76개와 빌드 통과. 기존 실제 고추기름 사진의 국가 OCR을 재확인하고, 실제 식약처 자료로 만든 **합성 시험 이미지**에서 제품명 자동 입력→실조회→문구 대조→중국 국가 일치 결과·JSON 내보내기를 검증했습니다. 이 시험은 실제 휴대전화 촬영·제품명 정확도 평가가 아닙니다. 자세한 기록은 `validation/integrated-flow-export.json`, `validation/name-ocr-modes.json`과 VALIDATION_REPORT.md를 참고하세요.

> **2026-10-25 실연결 확인:** 인증키 적용 후 ‘초콜릿’ 검색이 HTTP 200으로 성공했습니다. 총 1,631개 신고 자료 중 첫 10건 모두 제조국과 한글표시사항을 포함했고, 앱 결과 표시·2페이지 이동·캐시를 확인했습니다. 실제 `items: [{item: ...}]` 응답 구조를 반영했습니다. 아래의 인증키 미확보·실응답 검증 전 표기는 이전 작업 이력입니다. 기록: `validation/mfds-live-check.json`.

사진에서 제조국·원산지 표시를 읽고 사용자가 원문을 확인하는 웹앱입니다. 중국산의 진위나 표시 위반을 검증하는 서비스가 아닙니다.

식약처 서버 실연결을 확인했습니다. 인증키 발급과 `.env.local` 설정, 실제 응답 점검 방법은 [MFDS_SETUP.md](MFDS_SETUP.md)를 따릅니다. 제품 찾아보기에서 한국어·영어 제품명과 선택 수입업체로 조회합니다. 검색 후보의 제조국·수출국·제조업소·원문을 구분해 표시하며 자동으로 구매 제품의 국가를 확정하지 않습니다.

## 실행

Node.js 24에서 확인했습니다. 패키지 버전은 `pnpm-lock.yaml`에 고정되어 있습니다.

```sh
pnpm install
pnpm prepare:ocr
pnpm dev
```

현재 PC에는 `npm` 명령이 없고 pnpm이 런타임에 있습니다. PowerShell에서는 다음으로 실행할 수 있습니다.

```powershell
& 'C:\Users\SVSCORP\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd' run dev
```

기본 주소는 http://127.0.0.1:5173/ 입니다. `public/ocr`에 모델을 이미 준비했으면 재다운로드하지 않습니다. 이 버전은 로컬에서 검증했으며 외부 공개 배포하지 않았습니다.

```sh
pnpm test
pnpm build
pnpm preview
```

모바일 레이아웃 검증: 개발 서버의 `/mobile-preview.html`에서 390×844 iframe을 열 수 있습니다. 이 검증 페이지는 프로덕션 빌드에 포함하지 않습니다.

## 구현 범위

- JPEG·PNG·WebP 사진 입력, 기기 카메라 파일 선택, 회전, 드래그 영역 선택
- Tesseract.js 7.0.0의 기기 내 OCR, 한국어·영어·중국어·일본어 모델
- OCR 취소·시간 제한·실패 안내, 원문 수정, 확인 후 표시 분류
- 중국 표시 / 다른 국가 표시 / 확인 불가 / 복수 국가·상충
- 출처·원문·확인 시각 표시, 사용자가 선택하는 JSON 내보내기
- 한국 판매 태그가 붙은 Open Food Facts 식품 30개 스냅샷 검색
- 한국어·영어·일본어·중국어 간체 UI, 공통 메뉴·후원 선택창
- 웹 앱 매니페스트와 동일 출처의 앱 파일 캐시. 오프라인은 불러온 파일 범위에서만 동작

사진과 OCR 문구는 화면 메모리에만 유지합니다. 언어 선택만 localStorage에 저장합니다. OCR 모델은 이 앱에서 제공하며 사진 업로드 API는 없습니다. 외부 제품 정보 링크는 사용자가 눌렀을 때 열립니다.

## 검증과 중요한 제한

자세한 결과는 `VALIDATION_REPORT.md`, 원자료와 실행 기록은 `validation/`에 있습니다.

- 한국 판매 제품 30개에서 제조 장소 필드 0개. 이 수치는 선택한 표본에 한정합니다.
- 실제 제품 사진 30장의 자동 전체 이미지 OCR은 누락과 오인식이 많았습니다. 제조국 판별 정확도로 환산할 수 없습니다.
- 별도 선택 영역에서 한국·중국 표시를 읽었고 실제 앱에서도 확인했습니다. 원문 확인을 생략하지 않습니다.
- 다른 표본에서는 DB의 중국 제조 태그와 일본 원산지 라벨 사진의 불일치를 발견했습니다. 같은 바코드라도 시장·로트·시점 차이 또는 입력 오류가 있을 수 있습니다.
- 식약처 API는 인증키 적용 후 실제 응답과 브라우저 조회를 검증했습니다. 키는 MFDS_SERVICE_KEY 서버 환경변수에만 저장하고 브라우저에 넣지 않습니다.
- 중국어·일본어 OCR 모델은 포함했으나 해당 언어의 실제 사진 정확도 평가는 아직 없습니다. UI 번역과 OCR 정확도 검증은 구분합니다.
- 카메라 실기기 촬영, Android AAB, Play 출시 검증은 미완료입니다. 이 PC에서 Android SDK 경로와 JAVA_HOME을 확인하지 못했습니다.

## 재현 스크립트

- `scripts/probe-data.mjs`: 공개 제품 데이터 표본과 환경별 HTTP 결과 저장. 외부 네트워크 필요.
- `scripts/collect-labels.mjs`, `scripts/collect-china-labels.mjs`: 초기 선택 이미지 수집.
- `scripts/collect-benchmark.mjs`: OFF 공식 AWS 이미지 데이터셋에서 30개 표본 원본 수집.
- `scripts/benchmark.mjs`: 원본 30개에 동일한 OCR 처리 적용.
- `scripts/validate-ocr.mjs`: 초기 10개 선택 이미지 OCR.
- `scripts/compare-ocr.mjs`, `scripts/validate-focused.mjs`: 영역 선택·전처리 비교.
- `scripts/validate-real-labels.ts`, `scripts/lookup-real-labels.ts`: 이번 수입식품 이미지 OCR 및 실제 식약처 조회. 로컬 이미지와 API 서버가 필요합니다.
- `scripts/evaluate-real-labels.ts`: 보존된 OCR·조회 결과와 육안 정답으로 수정 전후 필드 추출을 재평가합니다. 외부 요청하지 않습니다.
- `scripts/validate-ocr-improvement.ts --search`: v0.5.0의 픽셀 변환·OCR·자동 재검색을 실제 이미지로 재현합니다. `--reuse`는 저장 결과만 재평가합니다. 원본 이미지는 재배포 라이선스 미확인으로 로컬에만 있습니다.
- `scripts/validate-quantity-brands.ts --search`: v0.6.0 용량 재인식과 3개 새 브랜드의 조회를 검증합니다. `--reuse`는 저장된 OCR·조회만 재평가합니다.
- `tests/origin.test.ts`: 판정 규칙·바코드 검증 회귀 테스트. OCR 정확도 테스트가 아닙니다.
